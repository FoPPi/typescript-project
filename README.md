# TypeScript Проєкт

## Опис

Цей репозиторій містить практичну роботу №1 для навчання основам TypeScript. Проєкт демонструє роботу з базовими типами даних TypeScript (string, number, boolean) та налаштування середовища розробки.

## Структура проєкту

- `src/` — директорія з вихідним кодом TypeScript
- `dist/` — директорія з скомпільованим JavaScript кодом
- `tsconfig.json` — конфігурація TypeScript компілятора
- `package.json` — файл залежностей проєкту

## Встановлення залежностей

\`\`\`bash
npm install
\`\`\`

## Компіляція проєкту

\`\`\`bash
npm run build
\`\`\`

## Запуск проєкту

\`\`\`bash
npm start
\`\`\`

## Режим розробки (з автоматичною компіляцією)

\`\`\`bash
npm run dev
\`\`\`

## Гілки

- `main` — основна гілка для стабільних версій
- `develop` — гілка для розробки та тестування

## Автор

Практична робота №1
